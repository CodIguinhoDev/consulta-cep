Aplicação web desenvolvida em React para consulta de CEPs brasileiros, integrando uma API pública em tempo real.

Principais Funcionalidades:

Consulta de CEP em tempo real, consumo de API REST e exibição dinâmica de dados de endereço

Tecnologias:

React e API pública de CEP (ViaCEP)
